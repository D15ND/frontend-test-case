# Задание для рефакторинга: Интернет-магазин

## Реализовано:
- Внедрена FSD-архитектура(проект декомпозирован по слоям: app, features, widgets).
- Удалена дублирующая логика из стора.
- Исправил добавление значений в стор (без type).
- Добавлены функции очистки для таймеров в useEffect, чтоб избежать утечки памяти.
- Вычисления на клиенте мемоизированы через useMemo.
- Стили перемещены в css-модули каждого компонента для улучшения поддержки.
- Добавлены баррели и алиасы для лучшей читаемости импортов компонентов.
- Вынесены моковые данные товаров и пользователя в отдельные файлы для лучшей читаемости компонентов.
- Большие компоненты декомпозированы на несколько, для лучшей читаемости и поддержки.

## Описание проекта

Этот проект представляет собой простой интернет-магазин, написанный на React с использованием Redux Toolkit. **Код содержит типичные антипаттерны**, которые необходимо исправить.

## Цель задания

Ваша задача - провести рефакторинг кода, улучшив его качество, читаемость и поддерживаемость.

## Функциональность

Приложение включает:
- Каталог товаров с фильтрацией и поиском
- Корзину покупок
- Добавление/удаление товаров
- Изменение количества товаров
- Оформление заказа

* рефакторинг стилей и верстки оцениваться не будет

## Требования к виду результата
1. Ссылка на гит репозиторий проекта
2. Текстовый файл, с описанием внесенных изменений в проекте, и решенных в нем проблем.


## Инструкции по запуску

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект:
```bash
npm run dev
```

3. Откройте браузер по адресу `http://localhost:5173`
